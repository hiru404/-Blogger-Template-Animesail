# ⛵ AnimeSail - Blogger Template Streaming Anime & Donghua

**AnimeSail** adalah template Blogger (Blogspot) khusus untuk website streaming video, anime, donghua, dan film. Desain dan tata letak antarmuka template ini secara khusus **terinspirasi dari situs ww2.anisail.info**, yang kemudian dikembangkan dengan pendekatan *Mobile-First* dan *Dark Mode* modern untuk memberikan pengalaman menonton (UI/UX) terbaik layaknya platform streaming premium.

## ✨ Fitur Unggulan

- **Responsive & Mobile Friendly:** Tampilan dioptimalkan untuk kenyamanan navigasi satu tangan di smartphone.
- **Dark Mode UI:** Tampilan gelap yang elegan dan mengurangi kelelahan mata saat menonton.
- **Dynamic Homepage:** Dilengkapi widget *Episode Terbaru* (Grid Layout) dan *Lagi Rame/Trending* (List Layout).
- **Tab Kategori Interaktif:** Filter cepat untuk "Semua", "Anime", dan "Donghua" tanpa *reload* halaman.
- **Episode Grid System:** Navigasi chapter/episode berbentuk grid angka yang sangat rapi (mendukung *dropdown* untuk episode panjang).
- **Post Generator:** Alat khusus (Generator Post) untuk memudahkan admin membuat halaman Series maupun halaman Episode baru hanya dengan *copy-paste*.
- **SEO & Speed Optimized:** Struktur kode yang bersih, dilengkapi *Lazy Loading* untuk gambar dan Iframe video player.
